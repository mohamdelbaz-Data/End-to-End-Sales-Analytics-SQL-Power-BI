# End-to-End-Sales-Analytics-SQL-Power-BI

## Overview

This project presents a complete sales analysis solution built using SQL and Power BI. The objective is to transform raw sales data into meaningful business insights through data analysis, KPI tracking, and interactive dashboards.

## Project Goals

* Analyze sales performance across different regions.
* Identify top-performing products and customers.
* Monitor monthly sales trends.
* Measure key business metrics.
* Build an interactive dashboard for decision-making.

## Tools & Technologies

* SQL
* Power BI

## Database Structure

The project is based on four main tables:

* Customers
* Orders
* OrderDetails
* Products

## SQL Analysis

The SQL phase included:

* Data Exploration
* Aggregate Functions
* GROUP BY Analysis
* Joins
* Subqueries
* Window Functions
* Business Performance Analysis

### Sample Business Questions

* Who are the top customers by sales?
* Which products generate the highest revenue?
* What are the best-performing regions?
* How do sales change over time?
* Which categories contribute the most to revenue?

## Dashboard Features

### KPI Cards

* Total Sales
* Total Orders
* Total Customers
* Average Order Value

### Visualizations

* Monthly Sales Trend
* Sales by Region
* Sales by Category
* Top Customers
* Top Products

### Interactive Filters

* Region
* Category
* Order Date

## Key Insights

* Identified the highest-performing sales regions.
* Highlighted top customers contributing to revenue.
* Tracked monthly sales performance trends.
* Evaluated product and category performance.
